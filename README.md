# HR Cloud 🌥️

A responsive, modern frontend application designed to streamline HR operations — built using **React**, **Tailwind CSS**, and **Framer Motion**.

---

## 🚀 Features

- 👥 Employee Tracking
- ⏱️ Attendance Management
- 💰 Payroll Insights
- 📝 Leave Approvals
- 📩 Contact Form
- 📱 Fully responsive design

---

## 📁 Project Structure

hr-cloud/ ├── public/ ├── src/ │ ├── components/ │ ├── pages/ │ └── App.jsx ├── tailwind.config.js ├── postcss.config.js └── package.json

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- React Router DOM
